# Cadence v3.2

An Apple Music-inspired theme and Studio suite for Spotify Desktop powered by Spicetify — **zero Python or extra runtimes required**.

## One-Command Install (Copy & Paste)

### Windows (PowerShell)
```powershell
iwr -useb https://raw.githubusercontent.com/tripydro123/cadence/main/install.ps1 | iex
```

### macOS & Linux (Terminal)
```sh
curl -fsSL https://raw.githubusercontent.com/tripydro123/cadence/main/install.sh | sh
```

## Features
* **Apple Music Vibrancy UI:** Frosted glass sidebars, floating player dock, SF-style typography, and rounded album cards.
* **5 Built-In Color Schemes:** `Dark`, `Light`, `Midnight`, `Rose`, and `Graphite`. Switch anytime with:
  ```sh
  spicetify config color_scheme Midnight
  spicetify apply
  ```
* **Cadence Studio Modal:** Live Accent & Surface color wheels, 5-band Web Audio EQ, spatial stereo widening, and banner suppression.
* **Karaoke Vocal Capsule HUD:** Floating vertical microphone slider for center-channel vocal attenuation.

## Prerequisites
* [Spotify Desktop](https://www.spotify.com/download/)
* [Spicetify CLI](https://spicetify.app/docs/getting-started)
